- [ ] รุ่นใหม่ล็อกอิน Netlify ได้ + ลอง deploy ทดสอบ 1 ครั้ง (ดูข้อ 4)

- [ ] ส่งไฟล์คู่มือทั้งหมดให้รุ่นใหม่ (`คู่มือ-README.md` + ไฟล์นี้)

## 3. ขั้นตอนขึ้นปีการศึกษาใหม่ (ทำช่วงเปิดเทอม 1)

การเงินแยกชีตต่อปี — ปีใหม่ทำแบบนี้:

1. **สร้างชีตการเงินปีใหม่** จากเทมเพลต `google-sheets-templates/การเงิน.csv` แล้วเผยแพร่เป็น CSV (วิธีอยู่ในคู่มือหลัก §3)
2. **แก้ `js/config.js`:**
   ```js
   financeYears: [
     { label: 'ปีการศึกษา 2570', url: 'ลิงก์ CSV ชีตปีใหม่' },   // ← เพิ่มบนสุด
     { label: 'ปีการศึกษา 2569', url: 'ลิงก์เดิม' },              // ปีเก่ายังกดดูได้
   ],
   ```
   หรือถ้าปิดบัญชีปีเก่าแล้ว ย้ายไป `pastLedgers` แทน
3. ชีตประกาศ/เอกสาร/กิจกรรม ใช้ต่อได้เลย (มีคอลัมน์ปีการศึกษาอยู่แล้ว) หรือจะเริ่มชีตใหม่ก็ได้
4. **Deploy** (ข้อ 4) เพราะแก้ config.js = แก้ไฟล์ในเครื่อง

## 4. วิธี deploy (ทวน — เว็บนี้ใช้วิธีลากโฟลเดอร์)

> ⚠️ เว็บนี้**ไม่ได้**เชื่อม GitHub อัตโนมัติ — เพราะ `js/config.js` (ลิงก์ชีตจริง) ไม่อยู่ใน GitHub
> ต้อง deploy จากโฟลเดอร์ในเครื่องที่มี config.js เท่านั้น

1. เข้า [app.netlify.com](https://app.netlify.com) → เลือกไซต์ → แท็บ **Deploys**
2. ลากโฟลเดอร์เว็บทั้งโฟลเดอร์ลงช่อง "Drag and drop"
3. รอ ~30 วินาที → เปิดเว็บจริง กด `Ctrl+Shift+R` เช็ค 1 รอบ

จำง่าย ๆ: **แก้ชีต = ขึ้นเว็บเอง | แก้ไฟล์ในโฟลเดอร์ = ต้องลาก deploy ใหม่**

## 5. อัปเกรดเป็นโดเมนจริง + อีเมลชมรม

### จดโดเมน (~400–600 บาท/ปี จ่ายปีต่อปี)

| ตัวเลือก | ที่จด | หมายเหตุ |
|---|---|---|
| `.com` / `.org` เช่น `muslimclubkku.org` | Cloudflare Registrar (ราคาทุน) หรือ Namecheap | ง่ายสุด แนะนำ |
| `.in.th` เช่น `muslimclub.in.th` | ผู้ให้บริการในไทย (THNIC) | ดูไทย แต่ใช้เอกสารประกอบ |

> จดด้วย**บัญชีกลางของชมรม** และจ่ายจากเงินชมรม — อย่าจดในชื่อบุคคล เดี๋ยวส่งมอบยาก

### ต่อโดเมนเข้า Netlify (ฟรี รวม HTTPS)

1. Netlify → Site configuration → **Domain management → Add a domain**
2. ทำตามที่ Netlify บอก: ไปตั้งค่า DNS ที่ผู้จดโดเมน (ชี้ CNAME/A record มาที่ Netlify หรือย้าย nameserver มาใช้ Netlify DNS = ง่ายสุด)
3. รอไม่เกิน 1 วัน → Netlify ออกใบรับรอง HTTPS ให้อัตโนมัติ
4. อัปเดต `siteUrl` ในสคริปต์แจ้งเตือน + ลิงก์ในคู่มือ/โซเชียล

### อีเมลชมรม (เช่น `contact@muslimclubkku.org`) — ฟรี

- **ทางง่าย:** Cloudflare Email Routing — forward อีเมลขาเข้าไปที่ Gmail กลางของชมรม ฟรี ตั้งใน 5 นาที (ถ้าใช้ Cloudflare เป็น DNS)
- **ทางเต็มระบบ:** Zoho Mail แพ็กเกจฟรี — ได้กล่องจดหมายจริงในโดเมนตัวเอง

## 6. กติกาที่ขอให้รุ่นถัดไปรักษา

1. **อย่าแก้ไฟล์ใน `js/` และ `sw.js`** ถ้าไม่เข้าใจ — งานประจำทั้งหมด (ประกาศ/การเงิน/เอกสาร/กรรมการ) ทำผ่าน**ชีตกับ config.js เท่านั้น**
2. **อย่าเปลี่ยนชื่อหัวคอลัมน์ในชีต** — เว็บอ่านตามชื่อคอลัมน์ ถ้าเปลี่ยนข้อมูลจะหาย (เพิ่มคอลัมน์ใหม่ได้ ไม่กระทบ)
3. **อย่าเอา `config.js` ขึ้น GitHub** — มันถูกตั้งให้ไม่ขึ้นโดยอัตโนมัติอยู่แล้ว อย่าไปฝืน
4. ก่อนแก้อะไรใหญ่ ๆ ให้ก๊อปโฟลเดอร์สำรองไว้ก่อนเสมอ (หรือใช้ git)
5. ข้อมูลการเงินเป็นเรื่องความไว้วางใจของสมาชิก — ลงให้ครบ แนบหลักฐาน และอย่าลบย้อนหลัง
