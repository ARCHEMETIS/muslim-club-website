# 📝 วิธีทำ Google ฟอร์ม ให้คนในชมรมกรอกข้อมูลเข้าเว็บ

แนวคิด: **คนกรอกฟอร์ม → ข้อมูลลงชีต → เว็บแสดงเอง**

> ⭐ หัวใจสำคัญที่คนพลาดบ่อย: เมื่อผูกฟอร์มกับชีต Google จะสร้าง **แท็บใหม่ชื่อ "การตอบกลับของฟอร์ม 1"**
> → ต้อง **เผยแพร่แท็บใหม่นี้เป็น .csv แล้วเอาลิงก์ไปอัปเดตใน `config.js`** (ลิงก์จะเปลี่ยนจากเดิม)

---

## ขั้นตอนรวม (เหมือนกันทุกฟอร์ม)
1. สร้างฟอร์มที่ https://forms.google.com ใส่คำถามตามตารางด้านล่าง **(ชื่อคำถาม = ชื่อคอลัมน์ ต้องตรงเป๊ะ)**
2. ไปแท็บ **"การตอบกลับ" (Responses)** → กดไอคอน **ชีตสีเขียว** → สร้าง/เลือกสเปรดชีต
   → จะได้แท็บ **"การตอบกลับของฟอร์ม 1"** ที่มีคอลัมน์ **"ประทับเวลา"** + คำถามของคุณ
3. เปิดสเปรดชีตนั้น → **ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ** → เลือกแท็บ **"การตอบกลับของฟอร์ม 1"** → **.csv** → เผยแพร่ → คัดลอกลิงก์
4. วางลิงก์ใน `js/config.js`:
   - ลิงก์ชีต (.csv) → ช่อง `sheets.xxx` (แทนลิงก์เดิม)
   - ลิงก์ฟอร์ม (ปุ่ม "ส่ง" ของฟอร์ม) → ช่อง `forms.xxx` (ปุ่ม "➕ เพิ่ม" จะโผล่ในเว็บ)
5. เซฟ → รีเฟรชเว็บ (Ctrl+Shift+R)

## 📂 ฟอร์มเอกสาร
| คำถาม (ตั้งชื่อตรงนี้เป๊ะ) | ชนิดคำถาม |
|---|---|
| ชื่อเอกสาร | ข้อความสั้น |
| โครงการ | ข้อความสั้น / เลือกตอบ |
| ปีการศึกษา | เลือกตอบ (2569, 2570, …) |
| เทอม | เลือกตอบ (1, 2) |
| แนบไฟล์ | **อัปโหลดไฟล์** |

✅ ไม่ต้องมีคำถาม "ประเภทไฟล์/ขนาด/วันที่" — เว็บเดาชนิดไฟล์เอง, ใช้ "ประทับเวลา" เป็นวันที่, ดึงลิงก์จากไฟล์แนบให้เอง
> ⚠️ **สำคัญ:** ไฟล์ที่อัปผ่านฟอร์มจะ **ไม่เป็นสาธารณะโดยอัตโนมัติ** → คนนอกกดดาวน์โหลดไม่ได้
> วิธีแก้ครั้งเดียว: ไปที่ Google ไดรฟ์ หาโฟลเดอร์ที่ฟอร์มสร้าง(ชื่อประมาณ "ชื่อฟอร์ม (File responses)")
> → คลิกขวา → แชร์ → **"ทุกคนที่มีลิงก์"**  (ไฟล์ที่อัปหลังจากนี้จะเปิดได้หมด)

## 💰 ฟอร์มการเงิน  ← แนะนำเริ่มอันนี้ก่อน (ง่ายสุด ไม่มีไฟล์แนบ)
| คำถาม | ชนิดคำถาม |
|---|---|
| วันที่ | **วันที่ (Date)** |
| ประเภท | เลือกตอบ → ใส่ 2 ตัวเลือก: **รายรับ** / **รายจ่าย** |
| หมวดหมู่ | เลือกตอบ (บริจาค, การกุศล, สาธารณูปโภค, กิจกรรม, …) |
| โครงการ | ข้อความสั้น / เลือกตอบ (เช่น ละศีลอดรอมฎอน) |
| รายการ | ข้อความสั้น |
| จำนวน | ข้อความสั้น (ใส่ตัวเลขบาท เช่น 5000) |

## 📣 ฟอร์มประกาศกิจกรรม
| คำถาม | ชนิดคำถาม |
|---|---|
| หัวข้อ | ข้อความสั้น |
| วันที่ | ข้อความสั้น (เช่น 8 มิ.ย. 2569) |
| หมวดหมู่ | เลือกตอบ (ละหมาด, การกุศล, เรียนรู้, กิจกรรม) |
| รายละเอียด | ย่อหน้า |
| รูปภาพ | ข้อความสั้น (วางลิงก์รูปไดรฟ์ที่แชร์ "ทุกคนที่มีลิงก์") |
| ลิงก์ | ข้อความสั้น (ลิงก์ "อ่านต่อ" — เว้นว่างได้) |

> 💡 รูปประกาศแนะนำ **วางลิงก์เอง** (ไม่ใช้อัปโหลดไฟล์) เพราะคุมการแชร์เป็นสาธารณะได้ง่ายกว่า

## ✉️ ฟอร์มสมัครสมาชิก  ← ต่างจากอันอื่น! ไม่ต้องเชื่อมชีต
แค่สร้างฟอร์มถามอะไรก็ได้ (ชื่อ-สกุล, รหัสนักศึกษา, คณะ, เบอร์, เหตุผลที่สมัคร …)
→ เอา **ลิงก์ฟอร์ม** ไปวางช่อง `forms.membership` ใน `config.js`
→ เว็บจะ **ฝังฟอร์มทั้งอันแสดงในหน้าติดต่อ** ให้กรอกได้เลย (ข้อมูลไปเก็บในชีตของฟอร์มตามปกติ ไม่ต้องดึงมาแสดง)

## สรุปว่าต้องวางลิงก์อะไรที่ไหน
```js
sheets: {                          forms: {
  documents:     'csv เอกสาร',       documents:     'ฟอร์มเอกสาร',
  finance:       'csv การเงิน',       finance:       'ฟอร์มการเงิน',
  announcements: 'csv ประกาศ',        announcements: 'ฟอร์มประกาศ',
},                                   membership:    'ฟอร์มสมัครสมาชิก',
                                   },
```
