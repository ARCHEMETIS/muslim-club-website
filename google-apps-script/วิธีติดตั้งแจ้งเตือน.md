# 🔔 วิธีติดตั้งระบบแจ้งเตือนเข้ากลุ่มอัตโนมัติ

ระบบนี้ใช้ **Google Apps Script** (ฟรี อยู่ในบัญชี Google เดียวกับชีต) ทำ 2 อย่าง:

| แจ้งเมื่อไหร่ | แจ้งอะไร |
|---|---|
| ทุกชั่วโมง | 📢 มีประกาศใหม่ในชีต "ประกาศกิจกรรม" |
| ทุกเช้า 08:00 | 📋 งานฝ่ายที่ใกล้เดดไลน์ (ล่วงหน้า 3 วัน) หรือเลยกำหนดแล้วยังไม่เสร็จ |

---

## ขั้นที่ 1 — เลือกช่องทางกลุ่มที่จะให้เด้ง

> ⚠️ **LINE Notify ปิดบริการไปแล้ว** (มี.ค. 2025) ตอนนี้ตัวเลือกคือ:

| ช่องทาง | ค่าใช้จ่าย | ความยาก | เหมาะกับ |
|---|---|---|---|
| **Telegram** ⭐ แนะนำ | ฟรี ไม่จำกัด | ง่าย (10 นาที) | สร้างกลุ่มงานกรรมการแยก |
| **Discord** | ฟรี ไม่จำกัด | ง่ายที่สุด (5 นาที) | ชมรมที่มี Discord อยู่แล้ว |
| **LINE OA (Messaging API)** | ฟรีแบบมีโควตาข้อความ/เดือน | ยาก (ต้องสมัคร LINE Developers) | จำเป็นต้องเด้งในกลุ่ม LINE เดิมเท่านั้น |

### วิธีเอาค่าของแต่ละช่องทาง

**Telegram**
1. คุยกับ `@BotFather` ใน Telegram → พิมพ์ `/newbot` ตั้งชื่อบอท → ได้ **botToken**
2. ดึงบอทเข้ากลุ่มกรรมการ
3. หา **chatId**: ดึงบอท `@RawDataBot` เข้ากลุ่มชั่วคราว มันจะโชว์ `id` ของกลุ่ม (เลขติดลบ เช่น `-100123…`) เสร็จแล้วเตะออกได้

**Discord**
1. ที่ช่องข้อความในเซิร์ฟเวอร์ → ⚙️ ตั้งค่าช่อง → **Integrations → Webhooks → New Webhook**
2. กด **Copy Webhook URL** — ได้ **webhookUrl** จบเลย

**LINE OA**
1. สมัคร [developers.line.biz](https://developers.line.biz) → สร้าง Channel แบบ **Messaging API**
2. เอา **Channel access token** (ออกใน Messaging API tab)
3. ดึง OA เข้ากลุ่ม แล้วหา **groupId** (ต้องตั้ง webhook ชั่วคราวเพื่อดักค่า — ค้นหา "LINE get groupId" มีคู่มือหลายเจ้า)
4. ระวังโควตาข้อความฟรีต่อเดือนของ LINE OA — ถ้ากลุ่มคุยเยอะให้พิจารณา Telegram แทน

## ขั้นที่ 2 — ติดตั้งสคริปต์

1. เปิด [script.google.com](https://script.google.com) → **โปรเจ็กต์ใหม่** (ใช้บัญชี Google เดียวกับที่เป็นเจ้าของชีต)
2. ลบโค้ดเดิมทิ้ง → วางโค้ดทั้งหมดจากไฟล์ `แจ้งเตือนชมรม.gs`
3. กรอก `CONFIG` ด้านบนของไฟล์:
   - `channel:` ใส่ `'telegram'` / `'discord'` / `'line'` ตามที่เลือก
   - กรอกค่าของช่องทางนั้น (ช่องทางอื่นเว้นว่างได้)
   - `spreadsheetId` ของชีต**ประกาศกิจกรรม**และ**ตารางกิจกรรม** — เอาจากลิงก์ชีต ส่วนที่อยู่ระหว่าง `/d/` กับ `/edit`
     ```
     https://docs.google.com/spreadsheets/d/【ตรงนี้คือ ID】/edit
     ```
4. กด 💾 บันทึก

## ขั้นที่ 3 — ทดสอบ + เปิดใช้งาน

1. ที่แถบบน เลือกฟังก์ชัน **`testSend`** → กด ▶ Run
   - ครั้งแรก Google จะขอสิทธิ์ → กด **Review permissions** → เลือกบัญชี → **Advanced → Go to (ชื่อโปรเจ็กต์) → Allow**
   - ถ้ากลุ่มเด้ง "🔔 ทดสอบระบบแจ้งเตือน…" = เชื่อมสำเร็จ ✓
2. เลือกฟังก์ชัน **`setup`** → กด ▶ Run **หนึ่งครั้ง** — สคริปต์จะตั้งเวลาให้เองทั้งหมด

เสร็จแล้ว ✓ ไม่ต้องเปิดคอมทิ้งไว้ — Google รันให้เองบนคลาวด์

## คำถามที่เจอบ่อย

- **เปลี่ยนเวลาสรุปเช้า?** แก้เลข `atHour(8)` ในฟังก์ชัน `setup()` แล้วรัน `setup()` ใหม่
- **เตือนล่วงหน้ามากกว่า 3 วัน?** แก้ `deadlineDaysAhead` ใน CONFIG
- **ย้ายช่องทาง (เช่น Discord → Telegram)?** แก้ `channel` + กรอกค่าใหม่ → บันทึก จบ (ไม่ต้องรัน setup ใหม่)
- **หยุดแจ้งเตือนชั่วคราว?** ในหน้า Apps Script → เมนูซ้าย ⏰ Triggers → ลบทิ้ง (เปิดใหม่เมื่อไหร่ก็รัน `setup()`)
- **ส่งมอบรุ่นถัดไปยังไง?** โปรเจ็กต์ Apps Script ผูกกับบัญชี Google ที่สร้าง — ดู `docs/คู่มือส่งมอบรุ่น.md`
