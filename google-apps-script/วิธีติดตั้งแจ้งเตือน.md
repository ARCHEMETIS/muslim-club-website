# 🔔 วิธีติดตั้งระบบแจ้งเตือนเข้ากลุ่มอัตโนมัติ

ระบบนี้ใช้ **Google Apps Script** (ฟรี อยู่ในบัญชี Google เดียวกับชีต) ทำ 2 อย่าง:

| แจ้งเมื่อไหร่ | แจ้งอะไร |
|---|---|
| ทันที (เช็คทุกชั่วโมง) | 🚨 ประกาศที่มีคำว่า "ด่วน" |
| ทุกเช้า 08:00 | 🌅 สรุปรวม: ประกาศใหม่ + งานฝ่ายใกล้เดดไลน์/เลยกำหนด (ไม่มีเรื่อง = เงียบ) |
| ตลอดเวลา (เฉพาะ LINE) | 💬 สมาชิกพิมพ์ `เดดไลน์` / `ประกาศ` / `โควตา` ในกลุ่ม → บอทตอบทันที **ฟรีไม่จำกัด** |

## ขั้นที่ 1 — เลือกช่องทาง

> ⚠️ **LINE Notify ปิดบริการไปแล้ว** (มี.ค. 2025) ตัวเลือกปัจจุบัน:

| ช่องทาง | ค่าใช้จ่าย | ความยากตอนติดตั้ง |
|---|---|---|
| **Telegram** | ฟรี ไม่จำกัดข้อความ | ง่าย (~10 นาที) |
| **Discord** | ฟรี ไม่จำกัดข้อความ | ง่ายที่สุด (~5 นาที) |
| **LINE OA** | ฟรี **300 เครดิต/เดือน** (ซื้อเพิ่มไม่ได้ ต้องอัปแพ็กราคาพันกว่าบาท/เดือน) | ยากสุด (~30 นาที) แต่สคริปต์นี้ออกแบบให้อยู่ในโควตาฟรีได้ |

## 💡 เข้าใจโควตา LINE ก่อน (สำคัญมาก)

กติกาการนับของ LINE:

1. **Push (บอทส่งเอง) เข้ากลุ่ม = กินเครดิตตามจำนวนคนในกลุ่ม** — กลุ่ม 15 คน ส่ง 1 ครั้ง = 15 เครดิต ❗
2. **Reply (บอทตอบเมื่อมีคนพิมพ์หา) = ฟรี ไม่นับโควตา ไม่จำกัด**
3. ยัดหลายเรื่องใน push เดียว = นับเท่าเดิม

สคริปต์นี้จึงบริหารให้แบบนี้:

| กลไก | ประหยัดยังไง |
|---|---|
| ประกาศธรรมดา "พักเข้าคิว" รวมส่งเช้าเดียว | หลาย push → เหลือ push เดียว/วัน และส่งเฉพาะวันที่มีเรื่อง |
| ประกาศ "ด่วน" เท่านั้นที่ push ทันที | เรื่องไม่ด่วนไม่เปลืองเครดิต |
| คำสั่ง `เดดไลน์` `ประกาศ` ให้สมาชิกดึงเอง | ใช้ reply = ฟรีล้วน ใช้บ่อยแค่ไหนก็ได้ |
| Quota guard เช็คยอดจริงก่อนส่งทุกครั้ง | เหลือ < 30 เครดิต → งดส่งอัตโนมัติ ประกาศค้างคิวไม่หาย |
| พิมพ์ `โควตา` ในกลุ่ม | ดูเครดิตคงเหลือได้ตลอด (ฟรี) |

**งบประมาณโดยประมาณ** — ปรับรอบส่งได้ที่ `digestDays` ใน CONFIG:

| จำนวนคนในกลุ่ม | รอบ digest ที่แนะนำ | เครดิต/เดือน | อยู่ในโควตา 300? |
|---|---|---|---|
| 5–10 คน (แกนนำ) | ทุกวันที่มีเรื่อง (`[]`) | ~75–150 | ✅ สบาย |
| 15 คน | ทุกวันที่มีเรื่อง (`[]`) | ~225 | ✅ พอดี ๆ |
| **16–25 คน** | **จันทร์/พฤหัส (`[1,4]` — ค่าเริ่มต้น)** | **~180–240** | ✅ |
| 26–35 คน | สัปดาห์ละครั้ง (`[1]`) | ~120–160 | ✅ แต่ข่าวช้า — แนะนำแยกกลุ่มแกนนำดีกว่า |
| 36 คนขึ้นไป | — | — | ❌ ให้ push เข้ากลุ่มแกนนำเล็ก แล้วกลุ่มใหญ่ใช้พิมพ์ถาม |

> 👉 ใช้รอบ จ/พฤ ให้ตั้ง `deadlineDaysAhead: 4` (ค่าเริ่มต้น) เพื่อครอบคลุมช่องว่าง พฤหัส→จันทร์
> 👉 กลุ่มไหนก็ตาม (ใหญ่แค่ไหนก็ได้) ดึงบอทเข้าไปให้สมาชิก**พิมพ์ถามเอา** (`เดดไลน์`/`ประกาศ`) ได้เสมอ — ฟรีไม่จำกัด

## ขั้นที่ 2 — เตรียมค่าของช่องทางที่เลือก

**Telegram** — คุยกับ `@BotFather` → `/newbot` → ได้ **botToken** · ดึงบอทเข้ากลุ่ม · หา **chatId** ด้วย `@RawDataBot`

**Discord** — ตั้งค่าช่อง → Integrations → Webhooks → New Webhook → **Copy URL** จบ

**LINE OA** (ทำตามลำดับ):
1. สร้าง LINE OA ที่ [manager.line.biz](https://manager.line.biz) (ใช้บัญชี LINE ของชมรม/บัญชีกลาง)
2. เปิดใช้ Messaging API: LINE Official Account Manager → ตั้งค่า → Messaging API → เปิดใช้ (ระบบพาไปสร้าง Channel ที่ LINE Developers)
3. ที่ [developers.line.biz](https://developers.line.biz) → Channel ของเรา → แท็บ **Messaging API** → ล่างสุดกด **Issue** ตรง *Channel access token (long-lived)* → คัดลอกเก็บไว้ (ออกครั้งเดียว ใช้ได้ตลอด ไม่ต้องต่ออายุ)
4. อนุญาตให้บอทเข้ากลุ่มได้: LINE OA Manager → ตั้งค่า → ตอบกลับ/แชท → เปิด **"เข้าร่วมกลุ่ม" (Allow join group chats)** และ**ปิด "ข้อความตอบกลับอัตโนมัติ"** (ไม่งั้นบอทจะสแปมกลุ่ม)

## ขั้นที่ 3 — ติดตั้งสคริปต์

1. เปิด [script.google.com](https://script.google.com) → **โปรเจ็กต์ใหม่** (บัญชี Google เดียวกับเจ้าของชีต)
2. วางโค้ดจาก `แจ้งเตือนชมรม.gs` ทับของเดิมทั้งหมด
3. กรอก `CONFIG` ด้านบน:
   - `channel:` → `'line'` (หรือ telegram/discord)
   - ค่าของช่องทางที่เลือก (LINE ใส่แค่ `channelAccessToken` พอ — `to` เว้นว่างได้ เดี๋ยวบอทจำเอง)
   - `spreadsheetId` ของชีต**ประกาศกิจกรรม**และ**ตารางกิจกรรม** (ตัวอักษรระหว่าง `/d/` กับ `/edit` ในลิงก์ชีต)
4. 💾 บันทึก → เลือกฟังก์ชัน **`setup`** → ▶ Run (อนุญาตสิทธิ์ตอนถูกถาม: Review permissions → Advanced → Go to → Allow)

## ขั้นที่ 4 (เฉพาะ LINE) — เปิด webhook ให้บอทหูตาดี

1. ในหน้า Apps Script → ปุ่มน้ำเงิน **Deploy → New deployment** → ⚙️ เลือก **Web app**
   - Execute as: **Me** · Who has access: **Anyone**
   - กด Deploy → คัดลอก **Web app URL**
2. ที่ LINE Developers → แท็บ Messaging API → **Webhook URL** → วาง URL → เปิดสวิตช์ **Use webhook**
   > ปุ่ม "Verify" อาจฟ้อง error — **ไม่เป็นไร** (Apps Script ตอบแบบ redirect ซึ่งปุ่มทดสอบไม่ชอบ แต่ใช้งานจริงได้ปกติ) ให้ทดสอบของจริงตามข้อ 3 แทน
3. ดึงบอท (LINE OA) เข้ากลุ่มกรรมการ → พิมพ์ `id` ในกลุ่ม
   - บอทตอบ ID กลับมา = webhook ทำงาน ✓ และบอทจำกลุ่มนี้เป็นเป้าแจ้งเตือนแล้ว
4. กลับมาที่ Apps Script → รัน **`testSend`** → กลุ่มต้องเด้ง "🔔 ทดสอบระบบ…" ✓

> 📝 ทุกครั้งที่แก้โค้ดใหม่ ต้อง **Deploy → Manage deployments → ✏️ → Version: New version** ไม่งั้น webhook ยังใช้โค้ดเก่า

## คำสั่งที่พิมพ์ในกลุ่มได้ (LINE — ฟรีทั้งหมด)

| พิมพ์ | บอทตอบ |
|---|---|
| `เดดไลน์` | งานฝ่ายที่ใกล้กำหนด/เลยกำหนดตอนนี้ |
| `ประกาศ` | ประกาศ 3 เรื่องล่าสุด |
| `โควตา` | เครดิตข้อความคงเหลือเดือนนี้ |
| `id` | ID ของห้องแชทนี้ |

## คำถามที่เจอบ่อย

- **เปลี่ยนเวลาสรุปเช้า?** แก้ `atHour(8)` ใน `setup()` แล้วรัน `setup()` ใหม่
- **เตือนล่วงหน้ามากกว่า 3 วัน?** แก้ `deadlineDaysAhead` ใน CONFIG
- **อยากให้ประกาศไหน push ทันที?** ใส่คำว่า **"ด่วน"** ในหัวข้อหรือหมวดหมู่ของประกาศนั้น
- **เครดิตหมดกลางเดือนจะเกิดอะไร?** บอทงดส่งเอง (ประกาศค้างอยู่ในคิว ไม่หาย) เดือนใหม่โควตารีเซ็ตก็ส่งต่อ — ส่วนคำสั่งพิมพ์ถามใช้ได้ตลอดเพราะฟรี
- **หยุดแจ้งเตือนชั่วคราว?** Apps Script → ⏰ Triggers → ลบทิ้ง (เปิดใหม่ = รัน `setup()`)
- **ส่งมอบรุ่นถัดไป?** โปรเจ็กต์ผูกกับบัญชี Google ที่สร้าง — ดู `docs/คู่มือส่งมอบรุ่น.md`
